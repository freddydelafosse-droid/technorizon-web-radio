# Plan d'enrichissement massif — Jaya Brain V1

Objectif : atteindre plusieurs milliers de faits **sourcés et structurés**, pas plusieurs milliers de lignes copiées.

## Multiplication des connaissances
Pour chaque artiste validé, la chaîne peut produire plusieurs objets :
- identité / alias / pays / période ;
- genres et tags ;
- discographie : releases / release-groups ;
- enregistrements/titres et collaborations ;
- relations entre artistes ;
- identifiants MusicBrainz et provenance.

200 artistes × plusieurs dizaines d'entités/faits exploitables permettent d'atteindre plusieurs milliers de connaissances après déduplication.

## Garde-fous
Les données générées restent dans staging. Aucune promotion automatique vers Brain V1.
Actualité, météo, résultats sportifs et autres données volatiles restent hors mémoire permanente.
